# Séance 11 GOA deck Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A ≈65-slide deck `slides/seance-11/` on les graphes orientés acycliques, taught Thursday 19 November 2026, 15h30–18h20.

**Architecture:** A pure JS module (`goa.js`) knows graph logic (descendants, paths, fork/chain/collision, open/closed, back doors) and is unit-tested with `node --test`. One Svelte component (`Goa.svelte`) draws any graph from a data definition and steps through click states, asking `goa.js` whether each highlighted path is open. Every graph of the deck is a named definition in `src/lib/data/seance11-goa.js`, so the drill keys are tested against the same data the slides draw. The R simulations are generated by `outils/seance11_data.R` into `src/lib/data/seance11.js`.

**Tech Stack:** SvelteKit 2 / Svelte 5 runes, SVG, `node --test` (Node built-in, no new dependency), R 4.6.2 + jsonlite.

**Spec:** `docs/superpowers/specs/2026-11-17-seance-11-goa-design.md`

- Bandeaux are CSS-uppercased: no X, Y, Z₁ or lone letters in a bandeau.
- Figures deterministic (no `Math.random`). Simulated data captioned « Données simulées ».
- Every R output on a slide comes from `seance11.js`, never typed.
- No `petit` Console on a teaching slide.
- `const TOTAL` equals the number of `<Slide>`s.

## Review Focus

1. A path whose collision is opened by controlling a **descendant** of the collision node (book p. 123) must read as open. Test in Task 1.
2. A node that sits on two paths (fork on one, chain on another) gets its type per path, not per graph. Test in Task 1 (figure 6.1 G: Z2 is a chain on X→Z2→Y and part of X→Z2→Z3←Y).

**Interfaces:**
- Consumes: `goa.js` (Task 1), `Flux.svelte` (`d`, `actif`, `arret`, `rouge`), `brancherTemps` from `../temps.js`.
- Produces: `<Goa graphe={GOA.nom} temps={[etat, …]} largeur={1600} hauteur={600} legende="" />` where each `etat` is `{ voir?: string[] (node ids shown; default all), aretes?: number[] (edge indexes shown; default all), controles?: string[], chemin?: string[], flux?: boolean | number[] (edge indexes with effect dots), coefs?: boolean, verdict?: string }`. One state = no click. Exposes nothing else.
- Drawing rules: nodes are text in Plex Mono, no circle; a controlled node gets a 3 px square frame in ink; arrows ink 2 px with a filled head, cause → effect; highlighted path: open = all its edges in the accent `--dk-accent`, thick, lit together (CSS transition only, resting image depends on state alone); closed = grey dashed, with a small bar across the edge next to the blocking node; `verdict` prints « Ouvert » (accent) or « Fermé » (grey) computed by `etatChemin`, never a prop string for open/closed (the `verdict` prop is only for extra words). Coefficients on arrows when `coefs`. Edges between the same nodes never overlap labels: arrow endpoints stop at the label's bounding box (measure with fixed character width of Plex Mono, 0.6 em).
