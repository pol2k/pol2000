Dans aes(), ou hors de aes() ?

dans aes() : R y voit une variable
ggplot(df_clean, aes(x = age, fill = "blue")) +
  geom_histogram(binwidth = 5)
hors de aes() : une couleur fixe
ggplot(df_clean, aes(x = age)) +
  geom_histogram(binwidth = 5, fill = "blue")
aes() relie une variable à une propriété du dessin.
